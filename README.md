# Toontown Infinite — Releases

Published builds of the Toontown Infinite launcher.

## Download

**[Get the launcher →](https://infinite.toontown.io/play)**

The download page picks the right file for you. If you'd rather choose by hand,
grab it from [the latest release](../../releases/latest):

| File | For |
| --- | --- |
| `Toontown Infinite-<version>-arm64.dmg` | Macs with Apple silicon (M1 and newer) |
| `Toontown Infinite-<version>.dmg` | Intel Macs |

Not sure which you have? Apple menu → About This Mac. "Chip" means Apple
silicon; "Processor" means Intel.

Windows and Linux builds aren't out yet.

## Updates

The launcher updates itself. It checks this repository on startup, downloads a
new version in the background, and offers to restart once it's ready. Anything
you've already launched keeps running, so an update never interrupts your game.
