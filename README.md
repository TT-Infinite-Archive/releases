# Toontown Infinite — Releases

Published builds of the Toontown Infinite launcher.

## Download

**[Get the launcher →](https://infinite.toontown.io/play)**

The download page picks the right file for you. If you'd rather choose by hand,
grab it from [the latest release](../../releases/latest):

| File | For |
| --- | --- |
| `Toontown-Infinite-Launcher-<version>-arm64.dmg` | Macs with Apple silicon (M1 and newer) |
| `Toontown-Infinite-Launcher-<version>.dmg` | Intel Macs |
| `Toontown-Infinite-Launcher-Setup-<version>.exe` | Windows |
| `tti-launcher_<version>_amd64.deb` | Debian, Ubuntu, and other apt-based distros |
| `tti-launcher-<version>-x86_64.AppImage` | Other Linux distros |

Not sure which Mac you have? Apple menu → About This Mac. "Chip" means Apple
silicon; "Processor" means Intel.

On Linux, prefer the `.deb` if your distro can install one: it registers the
launcher to handle sign-in and keeps itself current. The AppImage runs
anywhere but does neither on its own, so it's the fallback for distros the
`.deb` doesn't fit.

## Updates

The launcher updates itself on macOS, Windows, and the Linux AppImage: it
checks this repository on startup, downloads a new version in the background,
and offers to restart once it's ready. Anything you've already launched keeps
running, so an update never interrupts your game.

The `.deb` doesn't auto-update — reinstall the latest one to move versions.
